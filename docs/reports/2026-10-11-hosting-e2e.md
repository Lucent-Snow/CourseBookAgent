# 完整在线工作台的验收（2026-10-11）

## 实际范围

Vercel Hobby 上的完整 React / FastAPI 工作台、Private Blob 私有资料存档、Python Workflow 后台任务。默认游客，无个人 VPS，不要求账号注册，不启用付费套餐。生成核心提示词保持本轮适配前版本。

## 已验证

- 浏览器：完整资料库打开，新建资料集成功；既有九章预设阅读器显示书稿与章节内容。不是原先的静态 DemoApp。
- 两套独立游客身份：新建资料集及真实生成 Job 交叉访问返回 404；第二个游客没有继承第一个游客的模型配置与 Key；两个游客各自拥有正常预设。
- 云端 API：普通 Markdown 上传 201、解析 ready、预览与原文件一致；3,600,000 字节 Markdown 经两片上传，完成解析后字节数一致。测试资料集已删除。
- 私有存储：真实 Blob 强 ETag / 条件写入验收；发现大清单压缩响应导致弱 ETag 后改用 identity。自动回归覆盖并发不冲突合并及同文件冲突拒绝。
- 真实课堂三份资料、仅第 1 章：六次成功模型响应后 Job 达到 completed；章节包含四节；产物 API 返回 200；45,369 字节 Markdown 下载逐字节等于 Job 内 CourseBook 的正常渲染；刷新保持 completed。
- 生命周期：任务停止 200，刷新仍 interrupted；恢复 202，保留此前三个成功调用统计。默认 MiMo 深度思考的章节响应超过 235 秒，转为可恢复失败并保存前四步。显式快速模式恢复后完成章节和合成；网关小请求实际返回 reasoning_tokens=0。
- 短资料任务：另生成一章后手动停止，未继续重跑所有章节；不是第二次整书验收。
- 自动检查：后端与离线 123 项；前端 3 项、build、lint 通过。四条既有 Fast Refresh 警告及大包提示保留。

## 未通过与限制

浏览器扩展拒绝将本机文件放入文件选择器，提示文件 URL 权限；没有修改扩展设置。上传成功来自实际云端 HTTP 接口，不将其描述为浏览器手动上传通过。新产物读写由 API 验证，浏览器阅读验证使用完成预设。

默认 MiMo 深度思考的长章节在线生成失败；快速模式仅验证选定的一章，不能据此声称九章整书在线重跑稳定，也不等于内容事实审核。单次响应仍受平台时限限制。思考模式默认保留模型原有行为，使用者需自行选择快速模式。

校内账号登录、系统 PDF 和闲置游客自动回收未在本轮验收。模型 API 费用与免费托管额度分开；完成的步骤会存档，但网络中断或停止中的外部调用不能保证不计费。

正式地址 https://coursebook-demo.vercel.app/datasets 已 READY。未携带 Vercel 认证或自动测试通行标记的全新 HTTP 客户端访问工作台、API、预设及静态资源均为 200；新游客仅有一份预设，模型未配置，响应模式为 auto。预览与生成部署链接继续保护。
