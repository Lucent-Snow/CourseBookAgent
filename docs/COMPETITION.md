# 启真问智比赛定位与展示策略

## 1. 项目定位

本项目参加教育教学智能体赛道。

一句话：

> 基于智云课堂字幕的课程教辅生成智能体，把课堂回放沉淀为可阅读、可复习、可导出的结构化课程资产。

---

## 2. 不要讲太高级

不要把项目包装成：

- 重构教育生态。
- 全流程个性化学习平台。
- 完整师生机协同系统。
- 自动教材出版工具。

比赛里更容易讲清楚的是：

> 老师讲了一学期，智云里留下字幕和 PPT。我们把这些材料自动整理成一份讲义草稿。老师能改，学生能看，课程资产能沉淀。

---

## 3. 展示重点

现场/视频演示只展示一条路径：

```text
选课 → 获取资料 → 生成中 → 打开讲义 → 导出
```

不要让评委在聊天框里随便问。开放问答风险太高，而且会让产品变普通。

---

## 4. 评分维度对应

| 评分维度 | 对应话术 |
|---|---|
| 创新性 | 不是通用 RAG，而是面向课堂字幕 + PPT 的课程成书工作流 |
| 教学应用价值 | 降低教师整理讲义成本，帮助学生复习课程结构 |
| 技术实施质量 | 自动获取、清洗、对齐、结构化、生成、导出完整 pipeline |
| 用户体验与推广性 | 输入只是一门课，输出是一份可读讲义，流程简单 |
| 师生机协同 | 教师提供课程与审核，学生使用讲义复习，机器完成资料整理 |

---

## 5. 版权口径

> 系统仅处理教师授权或学生本人有访问权限的课程资料，生成结果用于课程内部教学改进与个人学习，不默认公开原始字幕、PPT 或完整课程内容。

---

## 6. 演示兜底

必须准备：

- 一份预生成讲义。
- 一份录屏。
- 本地缓存的字幕和 PPT。
- 无网络时也能打开的静态网页。
