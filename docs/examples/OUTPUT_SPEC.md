# 目标输出格式示例（教辅书）

本文档展示 CourseBookAgent 的成稿形态。当前状态：字幕-only，不处理 PPT。

## 全书结构

```markdown
# 课程名：课堂精讲与复习教辅

> 根据智云课堂字幕自动整理为复习教辅。课程 / 教师 / 学期。

## 前言          ← 终审生成：本书定位、结构、使用建议
## 如何使用本书   ← 学习建议
## 知识地图       ← 模块/主线说明
## 学习路径       ← 建议复习顺序
## 目录

# 第 N 讲：章节标题

> 模块：xxx主线 · 角色：核心方法|复习整合|专题/嘉宾

## 承上            ← 与上一章的衔接
## 学习目标        ← 3-5 条可检验目标
## 本章导读        ← 本章定位与内容概括
## 本章重点        ← 4-7 条重点
## 核心概念
## 先修概念
## N. 小节标题（重点）  ← 正文 + 组件 + 字幕时间段
## 课堂例子与补充
## 易错点
## 本章小结
## 启下            ← 引向下一章
## 来源            ← 字幕时间段索引
## 整理说明        ← ASR 不确定项

# 要点速记       ← 全书重点索引
# 全课术语表     ← 统一术语
# 连贯性阅读提示
# 来源索引
```

## 章节内组件

教辅书使用可复用组件（由主编定义，分章写作者按规范使用）：

| 组件 | Markdown 形态 | 用途 |
|---|---|---|
| `worked_example` | `> **【例题】** 标题 / 解题过程 / *来源：c015@12:30*` | 课堂例题完整展示 |
| `tip_box` | `> 💡 **标题** / 内容` | 易混概念澄清、记忆技巧 |
| `warning` | `> ⚠️ **标题** / 内容` | 课堂涉及的常见错误 |
| `procedure` | `> **【步骤】** 标题 / 步骤列表 / *适用：...*` | 标准化方法步骤 |
| `side_note` | `> 📝 内容 / *来源：...*` | 补充但不打断主线 |

## 来源链接

Web 版的关键内容带时间戳链接（可跳转字幕）；PDF/Markdown 保留文本引用：

```markdown
*字幕时间段：00:14-06:57 | 20:39-25:11*
```

## 质量底线

- 有全书主线与章际衔接（每章必须有承上/启下）
- 有学习目标、重点、易错点
- 核心方法章写清步骤、判定规则、适用条件
- 只使用字幕内容，不编造课堂外知识
- ASR 不确定处写入整理说明，不强行修正
