# ADR 011：成书文风与公开演示

已接受，2026-10-11，依据用户明确要求。

## 决策

- 课程资料确定主题与重点，允许补充必要的学科定义、背景、推导、示例和示意代码；采用正式出版教辅的书面表达，不要求逐句有字幕依据。
- 成品不展示待核查、来源备注或编辑警告；无法判断的具体细节省略。内部书稿保留来源与运行诊断，阅读投影不改写原始缓存。
- 旧书稿中带明确不确定标记的句子从阅读投影省略，不能只删标签后保留疑问结论。网页与 Markdown 使用同一呈现原则。
- 写作规则变更升级上下文指纹，旧章节缓存不冒充新文风产物；不自动重跑全书。
- Vercel 首版为独立静态公开演示：资料简介、已有九章教辅、目录与 Markdown 下载。通过 VITE_DEMO_MODE 构建，完整本地工作台继续使用原路由。公开版不连接本机生成、设置或校内登录接口。
- 仅显式导出所选书稿与演示简介，原始课堂文件、数据库、任务记录、凭据不上传，不提交产物到 Git。现有样例经过阅读投影，不声称由新提示词重新生成。
- 下载按 Job 内书稿渲染，防止同课程其他运行覆盖历史下载。

## 边界

静态演示适用于比赛展示，实时长任务与持久化生成后端另行部署；这次没有伪造实时生成过程。自动过滤旧编辑性句子是兼容措施，不替代新文风的真实生成抽样验收。
