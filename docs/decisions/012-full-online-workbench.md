# ADR 012：Vercel 完整工作台、游客隔离与免费额度

## 状态

2026-10-11，用户授权适配；实现与线上验收进行中。不得把静态演示视为完整部署。

## 决策

线上沿用提交版本 React App 和 FastAPI API，不维护缩减功能的演示版。不使用用户 VPS，不强制登录，不启用付费套餐。

默认签发随机游客凭据（HttpOnly、SameSite Cookie），服务端验证签名后绑定独立工作空间。所有资料、快照、运行、缓存、产物、模型配置及校内平台会话均按工作空间隔离。访客不能访问别人的资源；清除 Cookie 后无法找回原游客空间。管理员仍具有云服务管理权限，不能声称管理员技术上无法读取资料。

现有 SQLite 和文件契约保留为临时工作目录；Vercel 私有 Blob 保存内容寻址文件及工作空间清单，ETag 条件写入防止并发覆盖。临时目录不作为持久存储，跨请求恢复文件时重定位资料版本路径。清单按文件变更合并；同一文件冲突明确拒绝，不静默覆盖。仅 Cookie 所属空间可以通过 API 访问私有文件。

后台使用 Vercel Python Workflow 的持久步骤。每步最多新增一批模型请求，批内并发遵循用户配置，完成响应按请求内容保存到 Job 的重放日志。下一步仍运行相同 CourseBookPipeline 和 Agent，已完成模型调用使用日志返回值；不重写生成提示词，不将实验台接入产品。MiMo 的思考模式作为显式模型设置，默认 auto，不为赶时限静默截短正文；重放指纹包含该设置。每步限定在 Hobby 300 秒以内，过长调用显示失败并允许恢复。停止后已执行的外部模型调用不保证立即终止，但不允许覆盖停止状态或启动后续步骤。

公开预设由指定完成 Job 和输入快照导出，复制进游客自己的正常资料库。已有书稿明确标记为完成预设，查看不调用模型；新资料或重新生成仍走真实流水线。不能复制本机整个数据库、私人配置或登录会话。

## 免费边界

Vercel Hobby：函数单步上限 300 秒；Workflow 每月包含 50,000 事件、1 GB 写入，完成后的平台日志仅保留 1 天；Blob 包含约 1 GB 存储、10 GB 传输、2,000 次高级操作。超额度通常暂停服务，不能自动升级。完整产物必须独立存档，不能依赖 Workflow 短期日志。模型供应商的调用费用不包含在免费托管中，当前不授权向公开游客无限共享本机模型密钥。

## 验收

同站点完成预设阅读、新资料上传及真实生成、停止/恢复、刷新和新实例恢复、按 Job 下载一致性。两套游客 Cookie 交叉访问资料/运行/设置/平台会话必须拒绝。并发清单更新、重放不重复调用模型及停止竞态需要自动回归。所有功能必须逐项记录实际验证结果。
