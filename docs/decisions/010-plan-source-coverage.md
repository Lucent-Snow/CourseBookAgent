# ADR 010：规划资料覆盖校验与修复

2026-10-09；范围：生成核心的规划契约与章节缓存校验，不修改写作 prompt 或产品资料边界。

网页真实试跑 74397：模型规划 9 章，但没有有效的 resource_tags。旧 coercion 将 3 份资料按位置分给 c1/c2/c3，其他章空上下文；确定性回退又被当成成功。

决策：只在按资料生成的降级规划中使用位置映射。真实章节规划优先保留有效 Tag；缺失 Tag 时可以恢复模型明确给出的 section_plan.source_revision_ids，不猜测主题归属。仍有空上下文时，只请求一次独立 Tag 修复，保留原章节；修复后仍无资料则阻断生成。缓存规划同样校验。章节缓存只有正文存在、资料身份与当前上下文一致且非确定性回退时才复用。

全局资料可作为章节上下文；无 Tag 的资料仍可排除。此校验只保证有素材，不等于主题归属、内容覆盖或课程事实准确。拒绝响应识别、规划启发式质量与全书审校另列问题。

后续同轮验收发现 `_build_context_payload` 仅发送每份资料前 24 段，导致完整字幕被截成课堂事务。决定发送全部结构单元；输入过大由模型接口明确失败，不静默截断。LectureDraft 增加 `context_fingerprint`（章节指令、资料原文、全局 prompt 和组件规范的 SHA-256，带 full-source-v1 版本），流水线写入与复用时校验。旧缓存缺少指纹，下一次流水线恢复须重算；旧书稿仍保留可读，不改写既有产物。上一章衔接缓存遵守相同校验。

同轮后续：合法 JSON 含中文引号时，旧解析器先全局替换引号，损坏根对象并误取内部组件。现优先解析原文，其次修复尾逗号，最后才尝试智能引号修复。确定性回退/空正文在进度与缓存投影中计失败，整书显示部分完成。产品历史读取兼容 state 包装；模型统计回调接入运行状态，失败进入事件轨迹，按本轮尝试累计。上述不改变资料层或章节写作策略。
