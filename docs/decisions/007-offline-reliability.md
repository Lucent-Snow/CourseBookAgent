# ADR 007：离线可靠性与恢复契约

当前分支用于单进程、本地应用。任务记录位于 data/jobs/<job_id>.json，
独立的章节/蓝图快照位于 data/jobs/<job_id>/。服务启动将遗留 running/queued
标记 interrupted，不自动产生新模型调用。用户调用 retry 后复用成功快照，
只生成失败或未完成章节；空选择列表表示仅合成，None 表示全课。

任务 completed 只代表生成结束，不代表内容准确。质量报告保留确定性检查、
语义审校和人工确认三种状态；未进行语义审校不能标为 accepted。
来源覆盖率仅衡量小节引用是否都能定位到当前讲次字幕，不是事实准确率。

JSON/Markdown 关键产物原子替换。缓存清理保留任务快照与审校记录，
有排队或运行任务时拒绝清理。当前不支持多 worker、分布式任务队列、
跨版本 prompt 自动迁移；恢复时使用原任务蓝图与成功章节。

离线验收使用临时目录、MockTransport 和故障注入，不需要账号或 API key。
真实课程准确性、实际限流和智云播放器跳转必须另行联网验收。
