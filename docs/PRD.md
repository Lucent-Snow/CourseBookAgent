# CourseBookAgent 产品需求文档（PRD）

## 一、基础信息

| 项目 | 内容 |
|---|---|
| 产品暂名 | CourseBookAgent / 智课成书 |
| 比赛 | 第二届全国高校“启真问智”教育教学人工智能大赛 |
| 赛道 | 教育教学智能体 |
| 核心形态 | 课程字幕自动获取 + 教辅书生成 workflow |
| MVP 输入 | 一门课程 |
| MVP 输出 | 结构化课程教辅 Markdown / 网页 / PDF |

---

## 二、产品概述

### 2.1 目标用户

- 任课教师：希望沉淀课程内容、整理讲义草稿。
- 选课学生：希望在复习时快速获得结构化课程文本。
- 助教/课程团队：希望低成本整理课程资料。

### 2.2 核心场景

用户选择一门已有智云课堂记录的课程，系统自动获取带时间戳字幕，并将其整理为一份可阅读、可复习、可导出的课程教辅。

### 2.3 核心问题

高校课堂沉淀了大量回放、字幕、PPT，但这些资料通常没有被整理成稳定的课程资产：

- 字幕是口语流，不适合直接阅读。
- 字幕缺少章节边界，需要从教师讲解中恢复结构。
- 视频回放检索和复习成本高。
- 人工整理讲义耗时。

### 2.4 MVP 方案

**一键生成课程教辅**：输入课程，系统自动获取资料并生成教辅书。

## 三、本期范围

### 3.1 P0 必做

| 功能 | 说明 |
|---|---|
| 课程输入 | 支持写死示范课或从课程列表选择 |
| 字幕获取 | 自动获取讲次字幕 |
| 字幕清洗 | 去除口头语、重复、无效片段 |
| 知识单元切分 | 按讲次、时间段和主题切分 |
| 单章教辅生成 | 生成一章的结构化正文 |
| 全书教辅合成 | 合并为完整 Markdown |
| 网页展示 | 展示目录和正文 |

### 3.2 P1 加分

| 功能 | 说明 |
|---|---|
| 来源引用 | 标注讲次和字幕时间段 |
| PDF 导出 | 提升成品感 |
| 术语表 | 提取课程关键概念 |
| 单讲重生成 | 对某一讲重新生成 |

### 3.3 不做

| 功能 | 排除原因 |
|---|---|
| 主聊天框 | 容易变成普通 RAG Chat |
| 学生画像 | 需要额外学习行为数据 |
| 自动出卷主功能 | 可作为附属，不是 MVP 主线 |
| 垂域模型训练 | 时间和数据成本不匹配 |
| 全校平台 | 比赛阶段不需要 |

## 四、产品流程

```text
选择课程
    ↓
获取讲次列表
    ↓
获取每讲带时间戳字幕
    ↓
字幕清洗与时间段切分
    ↓
知识单元切分
    ↓
生成单章教辅
    ↓
合成全书教辅
    ↓
网页展示 / Markdown 导出 / PDF 导出
```

## 五、输入输出

### 5.1 输入

| 项目 | 说明 |
|---|---|
| 课程 ID / 课程名称 | 用户选择或系统预设 |
| 生成范围 | 全课 / 选定讲次，MVP 可先只做全课或一讲 |

| 数据 | 说明 |
|---|---|
| 讲次列表 | 课程下的视频/讲座列表 |
| 字幕 | 每讲 transcript |
| 课程元信息 | 教师、学期、课程名等 |

### 5.3 输出

| 输出 | 说明 |
|---|---|
| Markdown | 主输出，便于生成和修改 |
| Web 页面 | 比赛展示主形态 |
| PDF | 可选导出，增强正式感 |

## 六、AI 能力说明

AI 在本产品中负责：

1. 字幕清洗：把口语化字幕整理成可阅读文本。
2. 结构识别：根据字幕语义和时间段识别主题边界。
3. 知识点提取：提取概念、定义、例子、重点。
4. 教辅生成：把课堂讲解整理成章节正文。
5. 风格统一：让全书教辅格式一致。

AI 不负责：

- 编造课堂上没有讲的内容。
- 替代教师正式出版教材。
- 判断学生掌握程度。

## 七、验证标准

| 指标 | 定义 | MVP 目标 |
|---|---|---|
| 生成完成率 | 课程资料成功生成讲义 | 示例课 100% |
| 可读性 | 讲义是否能顺畅读完 | 人工判断可读 |
| 结构完整性 | 是否有目录、章节、小节 | 必须有 |
| 来源可追溯 | 是否能回到讲次和字幕时间段 | 必须有 |
| 演示稳定性 | 现场能否顺滑展示 | 必须稳定 |

## 八、风险

| 风险 | 应对 |
|---|---|
| 智云接口变化 | 准备预生成数据和缓存 |
| 字幕错误多 | 保留原文引用，生成时不强行扩写 |
| 内容版权 | 仅处理授权/权限内课程资料 |
| 生成太慢 | 后台任务 + 预生成示例 |
