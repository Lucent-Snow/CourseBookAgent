# 智课成书（CourseBookAgent）简版 PRD

> 2026-10-09 · 团队共同理解与比赛材料底稿。当前重点：把已经跑通的成书能力整理成可演示的产品。

## 1. 为什么做

一门课的知识散落在课件、录播字幕、讲义和个人笔记里。PPT 往往只有框架，字幕保留了讲解却充满口语；学生复习时需要反复翻文件、找回放、自己重建知识结构。

我们希望让学生把已有课程资料交给系统，得到一本有目录、有解释、有例题、可连续阅读的复习教辅。教师和助教也可以用它整理讲义草稿，再进行内容审核。

**产品主线：课程资料 → 一本教辅书。** 上传自己的资料是主路径；智云课堂、学在浙大接入是浙大学生的便捷选项。

## 2. 用户最终获得什么

输入可以是课堂字幕、PPTX、PDF、DOCX、Markdown 或 TXT。系统将资料组织成一本按知识主题划分的教辅，而不是把每次课的摘要按时间拼在一起。

成品包括前言和学习路径、章节导读与正文、例题和方法步骤、易错提醒、章节小结、术语表及来源说明。不确定的数字、转写或归属保留“待核”标记，便于后续审阅。

学生主要用来系统复习和查阅；教师、助教主要用来审核课程内容和沉淀讲义。

## 3. 产品怎么用

**建立资料集 → 上传或导入资料 → 确认本次使用的资料 → 启动生成 → 查看进度 → 阅读与导出。**

- 资料集长期保留课程资料，后续可以增加或更换材料。
- 每次生成锁定一份资料快照，明确“这本书用了哪一版资料”。
- 运行页面展示阶段、章节状态和需要处理的问题。
- 成品可以在网页阅读，目前系统支持导出 Markdown。

## 4. 工作流为什么这样设计

我们先让系统理解整门课，再按主题组织章节。主 Agent 负责全书规划，各章节 Agent 使用被分配的原资料撰写，系统负责固定的步骤和上下文组装。

| 步骤 | 解决什么问题 | 产出 |
|---|---|---|
| 解析资料 | 不同格式变成可读文本，保留来源位置 | 结构化资料 |
| 整理资料说明 | 说明每份资料讲了什么、独特价值和可用性，让主 Agent 看见全局 | 每份资料的五栏目说明 |
| 规划全书与打标 | 确定知识章节、顺序和写作要求，分配各份资料 | 全书蓝图与资料标签 |
| 按标签组装 | 为每章配齐相关字幕、课件、讲义和全局要求 | 章节上下文 |
| 分章撰写与检查 | 将材料组织成正文、解释、例题和易错点，记录质量问题 | 章节草稿 |
| 全书合成 | 排列章节，补充前言、知识地图、术语表及衔接 | 完整书稿 |
| 渲染输出 | 形成可阅读、可导出的成品 | 网页阅读内容与 Markdown |

一份资料可以服务多个章节，多份资料也可以组成一章。标签只决定资料分配，不改变工作流。每一步保留中间结果，便于单独查看和迭代。

## 5. 现在完成了什么

已经实现多格式上传、资料集和快照、主题式规划与打标、分章生成、章节检查、全书合成、网页阅读与 Markdown 导出。

10 月 9 日通过网页导入《概率论与数理统计》的三次真实课堂资料，生成九章、39 个小节、113 个教学组件。生成、停止、恢复、阅读和下载均通过界面操作；恢复复用了五章有效草稿，下载与流水线书稿逐字一致，没有另写正文。书稿刷新后仍可打开，待核说明可展开。

此次验收暴露并修复了资料选择、章节分配、原文截断、JSON 解析和状态展示问题，经过多次停止与恢复，不能称作首次运行无人干预成功。此前《数据科学与心理学研究》16 份字幕生成的 12 章和单独排版 PDF 确实来自流水线，但受旧输入截断影响，需重新审查资料覆盖，不能直接作为已充分验证的样例。

**目前证明的是：有限输入能经网页流程生成、恢复、阅读和下载教辅草稿。** 章节事实仍需教师核验；完整课程稳定性、完整重启恢复及多版本历史下载仍待验收。PDF 导出尚未接入系统，比赛公开网页尚未部署。

## 6. 比赛前重点补齐什么

| 工作 | 完成标准 |
|---|---|
| 产品展示 | 首次打开能理解用途，导入、生成和阅读主路径清楚，成品阅读舒适 |
| 恢复与保存 | 中断后记录还在，成功章节可复用，失败章节真正重跑，历史阅读/下载对应正确 |
| 预览与导出 | 真实教辅能从产品打开，PDF 导出可重复执行 |
| 可访问网页 | 评委通过稳定链接了解产品、预览获准成品、观看演示 |
| 比赛材料 | 内部文档、PPT、输入输出对照和录屏保持一致，有具体师生反馈 |

## 7. 判断标准与范围

关心三件事：资料是否被合理组织；教辅是否易读且有复习价值；用户能否顺畅完成生成、阅读和恢复。

比赛阶段集中做好这条主线。聊天、自动出卷、学生画像和全校平台暂不扩展。生成的是待审核的教辅草稿，不能把整理内容当作教师原话，也不能将待核结论当成已确认事实。

公开网页只展示获准内容。系统输出、单独排版、人工重试和教师审核的范围在演示与材料中如实说明。
